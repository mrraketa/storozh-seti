# Сторож сети

Программа для Windows, которая следит, чтобы интернет работал: VPN (Karing), обход блокировок (zapret), сайты и программы.

**[Скачать последнюю версию](https://github.com/mrraketa/storozh-seti/releases/latest/download/StorozhSeti.zip)** · [все версии](https://github.com/mrraketa/storozh-seti/releases)

## Что нужно заранее

Python ставить не нужно — он уже внутри архива (папка `python`).

1. **Karing** — [karing.app](https://karing.app) и ваша подписка VPN. Режим в Karing — «Правила».
2. По желанию **zapret** — [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube): YouTube и голос Discord без VPN. Распакуйте в «Загрузки», имя папки не меняйте.

## Как запустить

1. Распакуйте архив, например в «Документы».
2. Запустите `StorozhSeti.exe`.
3. На «Мониторе» нажмите **«Включить»** у строки «Сторож не запускается сам» — дальше сторож проверяет сеть каждые 10 минут сам. Права администратора не нужны.

## Что внутри

- **Монитор** — всё ли работает, скорость VPN, обрывы за сутки по часам, какие программы сейчас в интернете.
- **Программы** — для каждой программы: Авто / через VPN / напрямую / без интернета. Например, Steam — поставьте «VPN», если хотите через VPN.
- **Сайты** — проверить сайт напрямую и через VPN и пустить его как лучше.
- **Серверы** — скорость и надёжность серверов вашей подписки, «Замерить и выбрать лучший».
- **zapret** — работает ли YouTube напрямую, как идёт голос Discord, подбор стратегии, обновление zapret.
- **Журнал** и **Настройки** — всё, что сторож делает сам, можно выключить.

Claude по умолчанию идёт как всё остальное. Закрепить его за одним сервером: `storozh-seti\nastroyki.json` → `"claude_strana": "имя сервера как в Karing"`.

Всё работает на вашем компьютере, ничего не отправляется наружу. Исходники — в папке `ishodniki`.
